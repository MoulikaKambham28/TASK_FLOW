# 🚀 TaskFlow - Smart Productivity Management System

TaskFlow is a simple and interactive web-based productivity management application designed to help users manage their daily tasks efficiently.

The application allows users to create tasks, assign categories and priorities, search tasks, track completion status, and monitor productivity progress through a visual dashboard.

This project was developed as part of a web development internship to demonstrate frontend development skills using HTML, CSS, JavaScript, and Chart.js.

## Features
- Add and manage tasks
- Assign task categories (Study, Work, Personal)
- Set task priorities (High, Medium, Low)
- Search tasks
- Track total, completed, and pending tasks
- Display productivity progress using charts
- Light/Dark mode toggle

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js

## Purpose
The main goal of TaskFlow is to provide a simple and user-friendly platform for organizing daily activities and improving productivity through effective task management.
